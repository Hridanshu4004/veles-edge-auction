# Elevator Pitch

In decentralized edge computing, schedulers mistakenly assume the cheapest bid is the best. But when unreliable nodes fail, buyers suffer massive SLA losses. 

EdgeTruth completely ignores a node's promises. Instead, it tracks empirical execution evidence to estimate true reliability, then risk-adjusts node bids using a single, O(N) economic allocation equation. 

By paying contingently upon success, EdgeTruth aligns incentives, empirically resists Win-Then-Drop Sybil attacks, and dramatically reduces SLA failures in simulated environments.
