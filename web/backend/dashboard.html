What we do NOT claim

  • Collusion resistance is inconclusive — the adversary model tests a single colluding pair.
  • Nodes are synthetic — no real edge hardware is involved; only WS-DREAM network coordinates are real.
  • Only one Azure day (d01) is used — workload diversity is not representative of full traces.
  • The auction is NOT VCG — it is a prediction-contract / scoring-rule mechanism.
  • Regret numbers come from the simulator, not a real deployment.
