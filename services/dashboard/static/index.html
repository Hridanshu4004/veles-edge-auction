03 / HOW IT WORKS
01
Node Claims Distribution
Every node submits a probabilistic bid: success probability q, latency μ ± σ, and price b.
02
Expected Net Value
The mechanism selects the node maximising ENV = p·V − b − (1−p)·L. Lying raises b relative to ENV, never lowering it.
03
Staked Performance Bond
Nodes lock collateral C = q·(V+L)·γ. If SLA is breached, the bond is forfeited directly to the client — not vaporised.
04
Calibration Loop
After each task, the Brier score tracks prediction accuracy. Liars accumulate negative calibration history, reducing their future p_eff.
